# Backlog: known issues deferred to later stages

Issues spotted during the build and deliberately postponed. Each one has the
stage where it should be fixed and why it matters. Move an item to **Done**
(with the commit) once it's resolved. Put a new item in the group it serves
(portability, stability fixes, new features, minor improvements, other).

Stages: P1.3 validator · P1.4 fixes · P1.5 tests · P1.6 docs ·
P2 Unity import · P3 AI generation · P4 banners · P5 MCP agent + docs ·
P6 portability (a fresh clone on another machine, other Maya and Unity versions) ·
Later (production hardening: real, but not planned for any phase yet).

## Open

Grouped by what they bring to the goal: a plug & play tool that someone
else can clone and run. The stage column says when.
