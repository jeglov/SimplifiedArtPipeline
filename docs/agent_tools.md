# artpipe MCP tools (generated)

Generated by `artpipe agent docs` from the server's own tool list: do not edit
by hand. The guide is [agent.md](agent.md). Exit codes in every result: 0 pass,
1 the asset failed its checks or was handed over, 2 tool error. Gated actions
(writes outside `out/`) are not tools: they go through `queue_request`.


## Session

### `artpipe_info`

What this artpipe is: repo commit, the rules files (with sha256), the agent layer's pins, and whether the banner renderer's pinned tools are installed. Call it first in a session.

### `read_conventions`

Read a rules file from conventions/ (budgets, naming, textures, banner specs, repair policies, schemas). Never guess a number: read it here. name: e.g. mesh_budgets.yaml.

## Maya assets

### `list_checks`

List the checks (and fixes) you can run. domain: maya (scene checks + safe fixes), kit (game kit checks), banner (rendered banner checks). Each entry: id, severity (error blocks, warning informs), fixable, description.

### `run_check`

Run ONE Maya check on a scene (.ma/.mb/.fbx, repo-relative or absolute) for an asset class (conventions/mesh_budgets.yaml). Returns that check's result: passed, severity, message, metrics, offenders (component names). Warm Maya worker: well under a second.

| Parameter | Type | Required | Default |

### `apply_fix`

Apply ONE safe fix to a scene and re-validate the fixed copy with every check. The source is never touched: the fixed scene is written as .ma under out/agent/calls/. Returns what the fix did (or why it was skipped), the fixed file and the new report's summary and failing checks.

| Parameter | Type | Required | Default |

| `fix_id` | string | yes |  |

### `validate`

Validate a Maya scene (.ma/.mb/.fbx) against its asset class: every check, optional safe fixes (fix=True: a fixed .ma copy, the source is never touched) and optional FBX export of a passing asset (export=True). | Parameter | Type | Required | Default |

## Unity

### `unity_verify`

Re-check every asset already in the Unity project (Assets/Art) from the files, with no import cache: read-only. A job (Unity boots in batchmode, ~20 s warm).

## Approval queue

### `queue_request`

Ask a human to approve a GATED action (it writes outside out/): build (scene, asset_class, textures) and generate (subject, asset_class, style, name) import into unity/Assets; banners_art_hero (kit, concept_run), banners_art_background (kit, prompt, seed, repair) and banners_art_logo (kit) overwrite kit art; golden_rerecord changes the golden banner. params: a JSON object. reason: why, in a sentence a human reads before approving. Nothing runs until a human runs `artpipe queue approve ID`; then call queue_run(ID).

| Parameter | Type | Required | Default |
|---|---|---|---|
| `action` | string | yes |  |
| `params` | string | yes |  |
| `reason` | string | yes |  |

## Judgement

### `review_concept`

Look at a concept image the way an art director would. Returns the image, its mask and the concept checks' results, plus the questions no check can answer (wrong object, flat 2D drawing, text or logo, off-style). Judge them yourself, then call record_review; if it's wrong, retry_concept with a better subject.

| Parameter | Type | Required | Default |
|---|---|---|---|
| `concept_run` | string | yes |  |

### `review_banner`

Look at a rendered banner: its contact sheet (key frames decoded from the MP4) and its report, plus the questions the 17 checks can't answer (does the hero pop, natural line breaks, does it look like this game). Judge, then call record_review.

| Parameter | Type | Required | Default |
|---|---|---|---|
| `folder` | string | yes |  |
